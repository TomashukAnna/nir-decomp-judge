# Анализ требований WebGen-Bench

Здесь хранится выполненный вручную разбор трех ТЗ: иерархии требований, проверочные правила, их типы и неоднозначности с выбранными прочтениями.

Источник заданий: [WebGen-Bench — data/test.jsonl](https://github.com/mnluzimu/WebGen-Bench/blob/main/data/test.jsonl).

| Задание | ID |
| --- | --- |
| Игра 2048 | ID000013 |
| Fundraiser Day | ID000017 |
| Система учёта посещаемости | ID000048 |

Файлы:

- [webgen-three-tasks.docx](webgen-three-tasks.docx) — разбор трех примеров в форме doc.
- [webgen-three-tasks.md](webgen-three-tasks.md) — его текстовая версия для просмотра и обсуждения изменений на GitHub.

В разборе обозначение `code` означает детерминированную проверку, а `LLM` — проверку с помощью языковой модели. Правила здесь описаны, но ещё не реализованы как автоматические проверки. Приведённые прочтения и дополнительные предположения являются частью авторского анализа, а не результатами экспериментов.
