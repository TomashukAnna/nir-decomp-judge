# Анализ требований WebGen-Bench

Здесь хранится выполненный вручную разбор трёх заданий: иерархии требований, проверочные правила, их типы и неоднозначности с выбранными прочтениями.

Источник заданий: [WebGen-Bench — data/test.jsonl](https://github.com/mnluzimu/WebGen-Bench/blob/main/data/test.jsonl). Ссылка указывает на ветку main; точная версия исходного набора в исходном документе не зафиксирована.

Файлы:

- [webgen-three-tasks.docx](webgen-three-tasks.docx) — исходный авторский документ, скопированный без изменений.
- [webgen-three-tasks.md](webgen-three-tasks.md) — его текстовая версия для просмотра и обсуждения изменений на GitHub. Объединённые ячейки таблиц представлены текстом в первой ячейке и пустыми соседними ячейками.

В разборе обозначение `code` означает детерминированную проверку, а `LLM` — проверку с помощью языковой модели. Правила здесь описаны, но ещё не реализованы как автоматические проверки. Приведённые прочтения и дополнительные предположения являются частью авторского анализа, а не результатами экспериментов.

При последующих содержательных правках обновляйте обе версии документа, чтобы они оставались согласованными. В будущем рядом можно разместить структурированную разметку требований и ссылки на реализации проверок.
