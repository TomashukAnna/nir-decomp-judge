# DevAI: данные и результат пробного запуска

Материалы по issue #4. Используется DevAI из Agent-as-a-Judge (Zhuge et al.), а не WebGen-Bench.

## Источник и версия

- [Статья](https://proceedings.mlr.press/v267/zhuge25a.html).
- [Код и данные](https://github.com/metauto-ai/agent-as-a-judge), коммит `43c2fa7b84ef0c1522e8250576e6798bace29dd0`.
- Дата коммита источника: `2026-03-28T16:23:53+08:00`; скачано `2026-10-17T13:37:21.4084557+00:00`.
- [Датасет Hugging Face](https://huggingface.co/datasets/DEVAI-benchmark/DEVAI).

В `benchmark/devai/instances/` находятся 55 описаний задач с запросом `query`, требованиями `requirements`, их ID, зависимостями и критериями. В `benchmark/judgment/{OpenHands,MetaGPT,GPT-Pilot}/human_as_a_judge/` лежат отдельные человеческие оценки результатов каждого фреймворка: `satisfied` у требования и итоговый `satisfied_all_requirements` у задачи. Ответы Agent-as-a-Judge находятся в соседних каталогах `agent_as_a_judge/`; в этом спринте сам агентный судья не запускается.

Требование связывается с человеческой меткой по задаче, фреймворку и `requirement_id`; `satisfied=true` соответствует PASS, `false` — FAIL. Поля `satisfied=null` в исходных описаниях задач не являются человеческой разметкой. У части задач опубликованные критерии расходятся, поэтому ID нельзя без проверки считать полным подтверждением тождественности требований.

## Материалы по шагам задания

1. Версия и устройство данных описаны выше.
2. [Сводная таблица человеческой разметки](devai-human-labels-summary.md): все 55 задач и три фреймворка, выполненные и невыполненные требования, итоговые флаги полного выполнения и найденные расхождения. Сохранена проверенная студенткой версия текста.
3. [Доступность проектов](devai-workspace-availability.md): проверка GitHub, issue #36 и Hugging Face от **17.10.2026**. На эту дату найден только проект OpenHands для задачи 39; это датированный результат проверки, а не утверждение о текущем состоянии источников.
4. [Результат задачи 39](../results/devai/task39-local-004/comparison.md): сырой ответ модели, семь вердиктов, таблица сравнения, разбор расхождений и сведения о запуске. Совпали 5 из 7 оценок, MLflow run `062509bc4fcb43be98430081deb9bfe1`. Это проверка цепочки на одном примере, не оценка надёжности судьи.

## Воспроизведение

[Инструкция скачивания, сборки промпта и одного вызова модели](devai-smoke.md) содержит команды для PowerShell и Linux. Скрипт `decomp_judge.prepare_devai` читает данные непосредственно из зафиксированного Git-коммита и сохраняет хеш сообщений. Датасет и промпт находятся в игнорируемой папке `data/`; в Git добавлены только код, конфигурация, документы и результаты пробного запуска.

Для проверки уже полученного ответа обращаться к модели снова не требуется: [таблица CSV](../results/devai/task39-local-004/comparison.csv) содержит полные критерии, обе оценки, совпадение и причины модели. Источник человеческих меток и процедура сопоставления по ID указаны в отчёте. Человеческая разметка не включалась в промпт.

Ограничения пробного судьи: анализ статического текста без исполнения проекта; содержимое CSV, PDF и PNG модели не передаётся. Пять текстовых файлов передаются полностью, остальные артефакты представлены именами и размерами. Опубликованный проект не исправлялся. Успешный ответ получен с лимитом 16384 токена; запуск сохранил фактические настройки, коммит, seed и ID MLflow.
