# Подготовка пробного запуска DevAI

Работа по issue #4. Этот раздел описывает подготовку данных и промпта; ключ LLM для неё не нужен.

## Окружение

Нужны Git, Python >= 3.12 и uv. Команды выполняются из корня `nir-decomp-judge`; одинаковы для PowerShell и Linux:

```sh
uv sync --locked
```

## Скачать данные и собрать промпт

```sh
uv run python -m decomp_judge.prepare_devai --source data/external/agent-as-a-judge --output data/devai-smoke/task39 --download
```

Скрипт клонирует https://github.com/metauto-ai/agent-as-a-judge.git, если папки источника ещё нет. Git-коммит и задача берутся из `configs/devai-smoke.yaml`:

- коммит `43c2fa7b84ef0c1522e8250576e6798bace29dd0`;
- задача `39_Drug_Response_Prediction_SVM_GDSC_ML`;
- опубликованный проект OpenHands;
- ожидаемые ID требований: 0–6.

Файлы читаются непосредственно из объектов указанного Git-коммита. Размеры в дереве также берутся из Git, а не из рабочей копии с возможными CRLF. Поэтому размеры некоторых текстовых файлов отличаются от первоначального локального промпта, при сохранении их текста. Текущая ветка и переводы строк в рабочей копии источника не меняют новый промпт. Чужой код не исполняется. Дата подготовки и хеш сообщений сохраняются в manifest.

Если репозиторий уже скачан, его можно использовать без сети:

```sh
uv run python -m decomp_judge.prepare_devai --source ../agent-as-a-judge --output data/devai-smoke/task39
```

Выходная папка должна быть новой: существующие файлы не перезаписываются. Для повторной подготовки задайте другой `--output`.

## Результат подготовки

В выходной папке будут:

- `messages.json` — сообщения для модели;
- `prompt.txt` — читаемая копия запроса;
- `manifest.json` — версия данных, состав материалов и SHA-256 сообщений.

Системная инструкция находится в `configs/devai-system.txt`. Пользовательское сообщение содержит исходную задачу, требования, дерево проекта и полные тексты файлов `.py`, `.md`, `.txt`. Остальные файлы представлены путями и размерами. Папка `judge` исключена; человеческая разметка не читается и в запрос не включается. PDF, PNG и CSV не передаются содержимым.

`data/` уже исключена через `.gitignore`: исходный датасет и подготовленный промпт в Git не добавляются. В репозитории хранятся код сборки, конфигурация и системная инструкция.

## Проверка без модели

```sh
uv run python -m decomp_judge.devai_smoke --config configs/devai-smoke.yaml --messages data/devai-smoke/task39/messages.json
```

Ожидается `DRY RUN`, два сообщения и ID `[0, 1, 2, 3, 4, 5, 6]`. Это проверка входа, а не доступности модели. Инструкции настоящего запуска и сравнения будут дополнены на следующем шаге.
