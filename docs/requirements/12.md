# ТЗ № 12 — WebGen-Bench 000013

## Исходное ТЗ

Please implement a 2048 game website for users to play the 2048 game. The website should have functionalities for starting a new game, moving tiles, merging tiles, game over, and reviving. Users should be able to start a new game, move tiles up, down, left, or right, merge identical tiles, and win the game by achieving the 2048 result. If the game is over, users can choose to revive and continue playing. Choose linen for the background; set all component colors to maroon.
