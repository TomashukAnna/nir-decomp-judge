# ТЗ № 4089 — WebGen-Bench train_004090

## Исходное ТЗ

Please implement a multi-language supported website where users can choose different languages to browse the site. The website should have functionalities for user registration, login, browsing products, and placing orders. Users should be able to register an account, log in, browse product information in different languages, place orders for selected products, and view order status. Initialize the background color with light coral and component color with brown.
