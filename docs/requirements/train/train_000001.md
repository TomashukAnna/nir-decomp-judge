# ТЗ № 0 — WebGen-Bench train_000001

## Исходное ТЗ

Please implement a WeChat mini-program for managing orders and a promotion center for accompanying medical services. Users can add orders, view submitted orders, perform refund, cancellation, viewing, and payment operations. At the same time, users can enter the promotion center to view the promotion platform's commission benefits. The WeChat login function allows users to log in with their WeChat account. Users can browse the information of accompanying medical services, select service items, fill in relevant information, submit orders, and make payments. Set the background color to antique white and the component color to sienna.
