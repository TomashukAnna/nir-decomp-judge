# ТЗ № 1603 — WebGen-Bench train_001604

## Исходное ТЗ

Please implement a website for rendering graphics using WebGL. The website should have the functionality to render 2D and 3D graphics, and users should be able to upload their own model files and adjust rendering parameters such as lighting, materials, and colors. The website should also have real-time preview and interaction capabilities, allowing users to rotate, zoom, and pan the graphics. Apply light sea green as the background; style all components with medium sea green.
