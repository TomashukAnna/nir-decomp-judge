# ТЗ № 4344 — WebGen-Bench train_004345

## Исходное ТЗ

Please implement a website that uses the Google API to call Google services. The website should have functionalities for calling Google+, Drive, YouTube, and other services. Users should be able to log in and use the Google API to call Google services, such as uploading files to Google Drive, publishing videos to YouTube, and more. Initialize the background color with baby blue and component color with navy.
