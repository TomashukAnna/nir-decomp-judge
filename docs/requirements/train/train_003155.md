# ТЗ № 3154 — WebGen-Bench train_003155

## Исходное ТЗ

Please design a minimalistic website that includes a contact form and an e-commerce platform. The website should have a user-friendly interface that is easy to navigate. The contact form should allow users to input their name, email, and message, and send it to the website owner. The e-commerce platform should allow users to browse and purchase products, including product descriptions, prices, and images. Users should be able to add products to a shopping cart, view the cart, checkout, and make payments. Apply light slate gray for the layout background and navy for interactive elements.
