# ТЗ № 6277 — WebGen-Bench train_006278

## Исходное ТЗ

Please implement an online teaching platform for managing question banks, generating test papers, and analyzing student scores. The platform should have functionalities for question bank management, test paper generation, student answer sheet upload, and data analysis. Users should be able to log in, manage question banks, generate test papers, upload answer sheets, and view data analysis reports. The platform should support multiple question types and difficulty levels, and be able to automatically grade test papers and generate score reports. Set the background color to faint gray and the component color to slate gray.
