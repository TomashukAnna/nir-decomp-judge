# ТЗ № 273 — WebGen-Bench train_000274

## Исходное ТЗ

Please implement a data visualization webpage that displays various charts and graphs. The webpage should have the functionality to display different types of charts (such as bar charts, line charts, pie charts, etc.). Users should be able to customize the style and layout of the charts using simple CSS classes. The webpage should also have interactive features, allowing users to hover, click, and perform other operations to view detailed information about the charts. Apply light steel blue as the background; style all components with royal blue.
