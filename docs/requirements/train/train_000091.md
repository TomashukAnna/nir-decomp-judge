# ТЗ № 90 — WebGen-Bench train_000091

## Исходное ТЗ

Please implement a website that converts Figma designs to Wordpress Elementor templates. The website should have functionalities for uploading Figma design files, converting them to Elementor templates, and downloading the converted templates. Users should be able to register and log in to the website, upload their own Figma design files, select conversion options, download the converted Elementor templates, and manage their conversion history. Initialize the background color with mint and component color with dark sea green.
