# ТЗ № 5172 — WebGen-Bench train_005173

## Исходное ТЗ

Please implement a provincial committee office filling system website for online handling of institutional establishment application matters. The website should have functions such as opinion collection and common tools. Users should be able to log in, publish and fill out opinions, approve and remind, upload and download files, and conduct personalized surveys. Declare gold as the global background color and dark goldenrod for all UI pieces.
