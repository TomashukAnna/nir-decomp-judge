# ТЗ № 5246 — WebGen-Bench train_005247

## Исходное ТЗ

Please implement a locomotive crew management website for managing locomotive crew information. The website should have functionalities for adding, modifying, and deleting locomotive crew information. Users should be able to log in, browse locomotive crew information, add new crew members, modify existing crew information, delete unnecessary crew information, and generate statistics on crew information. Use moccasin as the default background and burlywood for component styling.
