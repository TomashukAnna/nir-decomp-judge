# ТЗ № 1982 — WebGen-Bench train_001983

## Исходное ТЗ

Please implement a visual database application creation tool for creating and managing databases. The tool should have functionalities for creating database schemas, inserting data, executing queries, and processing data. Users should be able to create forms to provide customized interfaces for their data and store all database objects, such as tables, queries, and forms. The tool should also allow users to edit and manage database structures, execute data queries and analysis, and more. Assign opal to the background and indigo to the UI elements.
