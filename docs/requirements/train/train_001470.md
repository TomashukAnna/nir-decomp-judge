# ТЗ № 1469 — WebGen-Bench train_001470

## Исходное ТЗ

Please implement a CSS preprocessor website to accelerate CSS coding. The website should have functionalities for code editing, syntax checking, preprocessing, and output. Users should be able to input CSS code, edit and check the code, use preprocessing features to accelerate coding, such as nested selectors and color mixing, and output the preprocessed CSS code. Assign lemon mist as the background color and apply dark orange to all elements.
