# ТЗ № 1057 — WebGen-Bench train_001058

## Исходное ТЗ

Please implement a college confession wall website for users to post and interact with confessions. The website should have functionalities for user authentication, posting confessions, interacting with others, searching, and personal center management. Users should be able to log in, post their own confessions, browse and reply to others' confessions, search for confessions of interest, and manage their personal center. Define the background as sky blue and components as steel blue.
