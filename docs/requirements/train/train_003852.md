# ТЗ № 3851 — WebGen-Bench train_003852

## Исходное ТЗ

Please implement a corporate WeChat self-service mall website that provides applications and services. The website should have functionalities such as a personal center, application payment and activation, message center, and single sign-on. Users should be able to log in, browse and purchase applications, manage personal information, receive message notifications, and use single sign-on to access different applications. The website should also have permission configuration, authorization management, and message push functions. Establish cream as the main background and dark teal for the controls.
