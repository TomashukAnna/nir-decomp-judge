# ТЗ № 2558 — WebGen-Bench train_002559

## Исходное ТЗ

Please implement a fast and simple application development platform for rapid development of various applications. The platform should have functionalities for project management, code editing, and debugging. Users should be able to log in, create new projects, edit code, debug applications, and manage project versions. Use sunlight as the screen background and gold for component highlights.
