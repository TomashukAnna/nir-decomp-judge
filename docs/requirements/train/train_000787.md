# ТЗ № 786 — WebGen-Bench train_000787

## Исходное ТЗ

Please implement an audiobook file editing website for merging and splitting audiobook files. The website should have functionalities for merging, splitting, and editing audiobook files. Users should be able to upload audiobook files, select merge or split options, edit file chapters, and download the edited files. Establish faint peach as the main background and coral for the controls.
