# ТЗ № 2396 — WebGen-Bench train_002397

## Исходное ТЗ

Please implement a debt management system for managing pre-loan, loan, and post-loan related businesses. The system should have functionalities for pre-loan quota issuance, customer management, project management, and credit management. Users should be able to log in, manage customer information, create and manage projects, perform credit management, and issue pre-loan quotas. The system should also be able to record and track loan and post-loan related business processes. Define background as azure; define components with slate blue.
