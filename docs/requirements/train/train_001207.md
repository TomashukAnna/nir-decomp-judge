# ТЗ № 1206 — WebGen-Bench train_001207

## Исходное ТЗ

Please develop a website for artificial intelligence and machine learning consultation, providing related services. The website should have functionalities for consultation services, project showcases, team introductions, and contact information. Users should be able to browse the website, understand the services provided, view project cases, learn about the team, and obtain consultation services through the contact information. Use a morning mist background and apply navy to the UI components.
