# ТЗ № 4387 — WebGen-Bench train_004388

## Исходное ТЗ

Please implement an asset management website for managing and tracking physical assets. The website should have functionalities for asset registration, asset inquiry, and asset statistics. Users should be able to log in, add, edit, and delete asset information, query detailed asset information, and statistics on asset quantities and distribution. Set the background color to pale turquoise and the component color to medium turquoise.
