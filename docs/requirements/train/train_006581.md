# ТЗ № 6580 — WebGen-Bench train_006581

## Исходное ТЗ

Please implement an in-vehicle multimedia system that displays weather forecasts, plays videos and music, and shows maps. The system should have the functionality to display local weather forecasts for the current day and the next five days, play local video files, control video playback, pause, skip, and progress bar operations, play music, display lyrics and song information, display the current location map, and zoom in and out of the map. Users can operate the system through a touch screen. Implement morning mist for the page background and navy for the elements.
