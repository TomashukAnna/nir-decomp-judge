# ТЗ № 3998 — WebGen-Bench train_003999

## Исходное ТЗ

Please implement a cross-border e-commerce big data analysis backend website for monitoring and analyzing e-commerce data. The website should have functionalities such as a monitoring center, product analysis, store analysis, hot search word analysis, industry analysis, site analysis, brand analysis, and live broadcast analysis. Users should be able to log in, browse and analyze various data, optimize their own stores, and enhance their competitiveness with competing products. Assign light steel blue to body backgrounds and dark slate gray to main components.
