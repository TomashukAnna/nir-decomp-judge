# ТЗ № 6378 — WebGen-Bench train_006379

## Исходное ТЗ

Please implement an integrated examination mini-program for students to take machine-based and mobile exams. The mini-program should have functionalities such as process assessment, score details, assessment plan, self-testing, and error collection. Students should be able to log in to the mini-program, take machine-based and mobile exams, view score details, self-test, view error collections, and accumulate errors. Choose light sky blue for the background; set all component colors to dodger blue.
