# ТЗ № 4591 — WebGen-Bench train_004592

## Исходное ТЗ

Please implement a command-line MQTT client tool for publishing and subscribing to messages. The tool should have functionalities for publishing messages, subscribing to topics, and receiving messages. Users should be able to publish messages to specific topics, subscribe to topics of interest, and receive messages from subscribed topics through the command-line interface. Assign papaya whip as the background color and apply peru to all elements.
