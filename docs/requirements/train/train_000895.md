# ТЗ № 894 — WebGen-Bench train_000895

## Исходное ТЗ

Please implement a game website called "Space Station Docking" for players to experience the game. The game should have functionalities for players to control fuel, jump to the next planet to refuel or score, and players need to follow the radar guide to effectively control the fuel, get a high score within the time limit, and reach the space station. Players can log in to the website, start the game, control the game character, get scores, and view rankings. Use blanched almond as the screen background and dark slate gray for component highlights.
