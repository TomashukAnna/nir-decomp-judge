# ТЗ № 1039 — WebGen-Bench train_001040

## Исходное ТЗ

Please implement a Baidu user registration page for user registration and login. The page should have functionalities for registration, login, and password recovery. Users should be able to input their username, password, email, and phone number to register, and after logging in, they can access their personal center and other related functions. The registration page should include input validation to ensure that the user's input information is legal and valid. Apply silver for layout; use dark slate blue for buttons and cards.
