# ТЗ № 6496 — WebGen-Bench train_006497

## Исходное ТЗ

Please implement an instant messaging system for real-time communication. The system should have the functionality to send and receive messages, supporting multiple types of messages including text, images, and videos. Users should be able to create and manage their own chat groups, add or remove group members, and set group permissions. The system should also have a file transfer function, allowing users to send and receive files. Set the background to bisque, and apply dark salmon to components.
