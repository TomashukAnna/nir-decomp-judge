# ТЗ № 835 — WebGen-Bench train_000836

## Исходное ТЗ

Please implement a data visualization website for Guizhou mobile data to display interactive personalized information. The website should have functionalities for overall overview, high-value, medium-value, and low-value data display. Users should be able to browse different types of data, view detailed information, and support drill-down functionality. The website should be able to respond to data changes in real-time, providing dynamic data visualization. Configure your theme with ghost white as background and cadet blue as component color.
