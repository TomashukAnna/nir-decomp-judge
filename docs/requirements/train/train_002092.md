# ТЗ № 2091 — WebGen-Bench train_002092

## Исходное ТЗ

Please implement an Oracle database development tool website that provides database development functions. The website should have functionalities such as text editing, SQL console, and common SQL tools. Users should be able to log in, use the text editor to write SQL code, execute SQL commands, and use tools for data analysis and management. Apply caramel to the canvas background and saddle brown to all visible components.
