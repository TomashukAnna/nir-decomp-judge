# ТЗ № 4173 — WebGen-Bench train_004174

## Исходное ТЗ

Please implement a Shu Yi Shao Xian Cao mini-program for selling products and managing orders. The mini-program should have functionalities such as product categories, ordering, order lists, personal centers, promotional activities, and points malls. Users should be able to browse products, place orders, view order lists, manage personal information, participate in promotional activities, and redeem points. Establish baby blue as the main background and navy for the controls.
