# ТЗ № 4926 — WebGen-Bench train_004927

## Исходное ТЗ

Please implement a website server management software for managing website servers. The software should have functionalities for adding, deleting, and modifying servers, managing server configurations, monitoring server status, and setting security policies. Users should be able to log in, browse the server list, add new servers, delete or modify existing servers, view server details, set server configurations, monitor server running status, and set security policies. Use rosy brown as the screen background and brown for component highlights.
