## Исходное ТЗ

Please implement a Chinese word segmentation web application where users can input Chinese text, and the application will automatically segment the words and display the results. The application should support multiple encodings (such as UTF-8, GBK) and have high-performance processing capabilities. Users should be able to select different segmentation modes and customize the segmentation dictionary. Select magenta for layout background and dark violet for component details.
