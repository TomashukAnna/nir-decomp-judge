# ТЗ № 990 — WebGen-Bench train_000991

## Исходное ТЗ

Please implement a cloud-based form designer website for designing and managing forms. The website should have functionalities for form design, data statistics, and filtering. Users should be able to log in, design and manage their own forms, and view data statistics and filtering results. The form designer should support various controls, including text boxes, drop-down menus, and checkboxes. Data statistics should support various charts, including bar charts, pie charts, and line charts. Use light sky blue for container backgrounds and dodger blue for component visuals.
