# ТЗ № 4534 — WebGen-Bench train_004535

## Исходное ТЗ

Please implement an SMS gateway website for sending and receiving text messages. The website should have functionalities for sending SMS, receiving SMS, managing SMS templates, and viewing SMS records. Users should be able to log in, send SMS to specific phone numbers, receive SMS from other users, manage SMS templates, and view historical SMS records. Design the site using ice blue as the background and teal for content blocks.
