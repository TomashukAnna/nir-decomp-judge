# ТЗ № 2103 — WebGen-Bench train_002104

## Исходное ТЗ

Please implement a blockchain smart contract development website for designing and deploying smart contracts. The website should have functionalities for designing, developing, and deploying smart contracts. Users should be able to log in, create, edit, and deploy smart contracts, view contract execution results, and manage contract-related data. Set light sea green as the body background and use dark slate gray for the UI.
