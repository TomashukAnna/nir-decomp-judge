# ТЗ № 4855 — WebGen-Bench train_004856

## Исходное ТЗ

Please implement a PHP application tracking and diagnostic tool to track and diagnose the running status of PHP applications. The tool should be able to display diagnostic results, including file, function, and calling function information. Users can run the tool to view diagnostic results and understand the application's running status. Use a dust white background and apply forest green to the UI components.
