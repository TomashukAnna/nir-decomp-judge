# ТЗ № 3192 — WebGen-Bench train_003193

## Исходное ТЗ

Please implement a website that dynamically generates PDFs based on database information to create pre-formatted PDF files. The website should have functionalities for logging in, displaying a list of available projects, user input fields, adding to cart, payment, and generating PDF files. Users should be able to log in, browse the list of available projects, input fields, add projects to the cart, pay for selected projects, and generate pre-formatted PDF files. The PDF files should have a tabular format, with each row populated based on data from the database. Apply peach as the background; style all components with orangered.
