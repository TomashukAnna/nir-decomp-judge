# ТЗ № 1568 — WebGen-Bench train_001569

## Исходное ТЗ

Please implement a website with instant messaging functionality for real-time message delivery. The website should have functionalities for sending messages, receiving messages, group chats, and private chats. Users should be able to log in and engage in real-time communication with other users, sending text, images, videos, and other types of messages, creating group and private chat sessions, and receiving messages in real-time. Apply honeydew to the canvas background and forest green to all visible components.
