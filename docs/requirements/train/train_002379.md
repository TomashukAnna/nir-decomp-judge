# ТЗ № 2378 — WebGen-Bench train_002379

## Исходное ТЗ

Please implement a mobile marketing campaign website for sending and managing text messages. The website should have functionalities for creating and editing text message templates, managing contact lists, sending and receiving text messages, and tracking the status of sent messages. Users should be able to log in, create and edit text message templates, manage contact lists, send text messages to selected contacts, and view the status of sent messages. Select light sky blue for layout background and dodger blue for component details.
