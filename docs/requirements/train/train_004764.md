# ТЗ № 4763 — WebGen-Bench train_004764

## Исходное ТЗ

Please implement a website translation system that supports multiple languages. The system should have an automatic translation function that can translate website content from one language to another. Users should be able to select the target language and browse the translated website content. The system should also have a manual translation function that allows users to edit and modify the translated content themselves. Set the background color to sunlight and the component color to gold.
