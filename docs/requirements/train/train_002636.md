# ТЗ № 2635 — WebGen-Bench train_002636

## Исходное ТЗ

Please implement an introductory website for food delivery by drones, to showcase the company's services and products. The website should have functionalities such as a homepage, about us, services, and contact us. Users should be able to browse the website, learn about the company's services, watch videos, view images, and submit contact information. The website should have a responsive design, adapting to different devices and screen sizes. Declare smoke as the global background color and midnight blue for all UI pieces.
