# ТЗ № 3060 — WebGen-Bench train_003061

## Исходное ТЗ

Please implement a smart comprehensive laundry cabinet system for managing laundry processes. The system should have functionalities for user login, laundry appointment, laundry status inquiry, and payment management. Users should be able to book laundry services, check laundry status, and make payments through a mobile app or mini-program. The system should also have backend management functions for managing laundry cabinet devices, advertising, and other related features. Style all pages with a cotton background and maroon components.
