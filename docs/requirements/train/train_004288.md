# ТЗ № 4287 — WebGen-Bench train_004288

## Исходное ТЗ

Please implement an electric vehicle charging appointment application for users to book charging and merchants to configure charging services. Users should be able to search for nearby charging stations, book charging appointments, and view charging records through the application. Merchants should be able to register through the application, configure their own charging stations, manage charging orders, and view charging data. Declare light sea green as the global background color and medium sea green for all UI pieces.
