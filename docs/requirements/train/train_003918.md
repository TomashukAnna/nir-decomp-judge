# ТЗ № 3917 — WebGen-Bench train_003918

## Исходное ТЗ

Please implement a map-based pet transportation platform website that connects service providers with clients. The website should have user login functionality, allowing clients and transporters to insert key information. The website should also have a map feature, recommending suitable transporters to clients based on their information. Clients should be able to browse transporter information, compare prices and services, and choose a suitable transporter. Transporters should be able to browse client requests, submit quotes, and manage their own orders. Style the layout with light yellow in the background and dark khaki for the interface.
