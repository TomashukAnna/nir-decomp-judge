# ТЗ № 6147 — WebGen-Bench train_006148

## Исходное ТЗ

Please implement a comprehensive Western medicine learning website that provides resources such as question banks, videos, and live streams. The website should have functionalities such as question banks, modules, videos, live streams, experience sharing, comments, discussion circles, note-taking, and error tracking. Users should be able to log in, browse and search the question bank, watch videos and live streams, participate in live interactions, share experiences and comments, join discussion circles, take notes and track errors, and view learning records. Set overall background to cream, then style components with dark teal.
