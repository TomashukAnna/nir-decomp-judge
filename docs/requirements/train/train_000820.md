# ТЗ № 819 — WebGen-Bench train_000820

## Исходное ТЗ

Please implement a music player application for playing and managing music. The application should have functionalities for playing, pausing, previous track, and next track. Users should be able to browse music lists, search for music, play selected music, view music details, and manage their own music playlists. Set baby blue as the body background and use navy for the UI.
