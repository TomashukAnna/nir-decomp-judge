# ТЗ № 5809 — WebGen-Bench train_005810

## Исходное ТЗ

Please implement a website to display unit test coverage, used to show code coverage. The website should have the functionality to display coverage, including displaying changes in coverage at different time points. Users should be able to log in, browse coverage data, view coverage at different time points, and analyze the trend of coverage changes. Apply desert sand as the background; style all components with sienna.
