# ТЗ № 6332 — WebGen-Bench train_006333

## Исходное ТЗ

Please implement a study abroad application to help students complete their study abroad applications and improve their language scores. The application should have matching and language score improvement functions to help students quickly find suitable study abroad institutions. Teachers can use the application to manage student information, recommend suitable study abroad programs based on students' scores and study abroad intentions. Students can browse and search for different study abroad institutions, view institution information, submit study abroad applications, and track application status. Set the background to magenta, and apply dark violet to components.
