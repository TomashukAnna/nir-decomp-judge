# ТЗ № 3285 — WebGen-Bench train_003286

## Исходное ТЗ

Please implement an e-commerce mini-program for online shopping and order management. The mini-program should have functionalities for online ordering, WeChat payment, shopping cart, order management, member management, flash sales, product categorization, product management, inventory management, category management, distribution, point redemption, and coupon usage. Users should be able to browse products, add them to the shopping cart, make online payments, view order status, manage personal member information, participate in flash sales, redeem points, and use coupons. Declare cool gray as the global background color and charcoal for all UI pieces.
