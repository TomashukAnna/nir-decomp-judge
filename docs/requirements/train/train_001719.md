# ТЗ № 1718 — WebGen-Bench train_001719

## Исходное ТЗ

Please implement an online form system for collecting and managing user information. The system should have functionalities for building forms, filling out forms, synchronizing data, and data interaction. Users should be able to create and edit forms, fill out form information, and submit forms. The system should be able to automatically save and update form data and provide data query and statistical functions. Define the background as gainsboro and components as dark slate blue.
