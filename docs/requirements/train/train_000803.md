# ТЗ № 802 — WebGen-Bench train_000803

## Исходное ТЗ

Please implement a speech recognition website for recognizing and transcribing speech. The website should have functionalities for speech input, recognition, transcription, and playback. Users should be able to log in, input speech, and the website will automatically recognize and transcribe the speech. Users can view and edit the transcription results and play back the original speech. Apply thistle to the canvas background and medium purple to all visible components.
