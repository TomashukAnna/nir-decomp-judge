# ТЗ № 3684 — WebGen-Bench train_003685

## Исходное ТЗ

Please implement an online marketplace platform similar to Amazon, allowing vendors to create shops and share products. Vendors can register and create their own shops, then invite other vendors to join the shop and share products. Each shop can have a maximum of 5-20 vendors. Vendors within a shop can chat with each other and view each other's sales results. Vendors can add their own payment methods, such as Stripe or PayPal. Users can browse shops, view products, place orders, and make payments. Set overall background to pewter, then style components with cadet blue.
