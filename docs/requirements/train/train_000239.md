# ТЗ № 238 — WebGen-Bench train_000239

## Исходное ТЗ

Please implement a Whac-A-Mole mini-program for mobile users' entertainment. The mini-program should have functionalities such as mobile authorization login, sending red packets, and playing Whac-A-Mole. Users should be able to log in to the mini-program, participate in the Whac-A-Mole game, receive rewards, send red packets to other users, and view their game records. Color the background using amber and set component styles to chocolate.
