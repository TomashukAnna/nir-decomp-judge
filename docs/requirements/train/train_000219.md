# ТЗ № 218 — WebGen-Bench train_000219

## Исходное ТЗ

Please implement a commercial network technology system for managing team and company data. The system should have user login, registration, password recovery, and password reset functions. The system should also have product approval, influencer binding, data overview, product shelving and unshelving, and shipping channel control functions. Users can view data summaries, historical records, and trend charts through the system. The system should also have carousel, data summary tables, and dynamic routing functions. Apply theme using light goldenrod as background and goldenrod for elements.
