## Исходное ТЗ

Please implement a website for the New Bank of Xinjiang's electronic commercial bill system to handle the offline processing of old bills. The website should have functionalities for prompting payment and tracking related operations, migrating old bill data, merging data, verifying data continuity, and verifying data. Users should be able to log in, browse old bill information, perform payment and tracking operations, view data migration and merging results, and perform data verification and verification. Implement styling with eggshell for the background and dark slate gray for components.
