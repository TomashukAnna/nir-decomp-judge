# ТЗ № 4160 — WebGen-Bench train_004161

## Исходное ТЗ

Please implement a payment system website for handling various payment services. The website should have functionalities for merchant center, agent center, payment center, and settlement center. Users should be able to log in, browse different services, perform payment operations, view payment records, and manage account information. The merchant center should allow merchants to manage their products and services, the agent center should allow agents to manage their agency business, the payment center should process payment requests, and the settlement center should process settlement business. Apply light yellow to the canvas background and dark khaki to all visible components.
