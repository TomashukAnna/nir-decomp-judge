# ТЗ № 4894 — WebGen-Bench train_004895

## Исходное ТЗ

Please implement a database structure comparison tool to compare the structures of different databases. The tool should support multiple database types, such as mysql, oracle, and sql server. Users should be able to select two databases for comparison, and the tool will display the differences in the structures of the two databases, including table names, field names, data types, and other information. Users can manually adjust the databases based on the comparison results to ensure consistency across different environments. Use eggshell as the screen background and dark moss green for component highlights.
