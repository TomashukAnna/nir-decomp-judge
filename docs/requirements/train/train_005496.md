# ТЗ № 5495 — WebGen-Bench train_005496

## Исходное ТЗ

Please implement a database management website for browsing and editing Access databases. The website should have functionalities for browsing table content, adding new records, editing existing records, and deleting records. Users should be able to log in, browse tables in the database, add new records, edit existing records, and delete unnecessary records. Set turquoise as the body background and use cadet blue for the UI.
