## Исходное ТЗ

Please develop a website with editing and search engine optimization capabilities. The website should have an editor feature that allows users to create and edit content. At the same time, the website should have search engine optimization functionality to improve the website's ranking in search engines. Users should be able to log in, create and edit content, optimize the website's keywords and descriptions, and view the website's traffic and ranking. Apply bisque for layout; use dark salmon for buttons and cards.
