# ТЗ № 2266 — WebGen-Bench train_002267

## Исходное ТЗ

Please implement a questionnaire management system for managing user and class information. The system should have the functionality to display all user information and class information, including users' basic information and classes' detailed information. Users should be able to log in to the system, browse and manage their own information, including modifying personal information and viewing class information. The system should also have the functionality to manage questionnaires, including creating, editing, and deleting questionnaires. Select ice blue for layout background and teal for component details.
