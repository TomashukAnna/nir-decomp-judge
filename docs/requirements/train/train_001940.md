# ТЗ № 1939 — WebGen-Bench train_001940

## Исходное ТЗ

Please implement a package secretary website for agents and manufacturers to manage orders and track production status. The website should have functionalities for order accounting, process tracking, real-time production status updates, and order billing. The agent version should allow agents to manage orders in cooperation with the company, and the manufacturer version should allow manufacturers to track the processing process and production status of various crafts. Users can log in to the website, browse order information, track production status, and generate order bills. Implement styling with light yellow for the background and goldenrod for components.
