# ТЗ № 1472 — WebGen-Bench train_001473

## Исходное ТЗ

Please implement a form tool system for generating and managing forms. The system should have functionalities for creating forms, editing forms, deleting forms, and exporting forms as Word or PDF files. Users should be able to log in, create new forms, edit existing forms, delete unnecessary forms, and export forms as Word or PDF files. Declare antique white as the global background color and sienna for all UI pieces.
