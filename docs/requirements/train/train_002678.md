# ТЗ № 2677 — WebGen-Bench train_002678

## Исходное ТЗ

Please implement a website that displays local business discount information. The website should have functionalities for displaying business information, discount details, navigation, and contacting businesses. Users should be able to browse the business list, view discount information, use the one-click navigation feature to navigate to the business location, and directly contact the business. Set the background color to pink and the component color to deeppink.
