# ТЗ № 4144 — WebGen-Bench train_004145

## Исходное ТЗ

Please implement a chain KTV management website that provides functions such as reservation, ordering, and rewards mall. The website should have functionalities for reservation, ordering, rewards mall, activity issuance, and various lottery activities. Users should be able to log in, browse products, activities, and room information, make reservations, order food, redeem points, and participate in lottery activities. Administrators should be able to log in, manage products, inventory, equipment maintenance, and view data analysis reports. Use cool gray in the background layer and charcoal for the component layer.
