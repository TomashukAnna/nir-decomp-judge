# ТЗ № 1462 — WebGen-Bench train_001463

## Исходное ТЗ

Please implement a website that generates XML-based forms. The website should have functionalities for creating, editing, and managing forms. Users should be able to log in, create new forms, edit existing forms, and manage created forms. Forms should support various field types, including text, selection, and date, among others. Users should be able to customize the layout and style of forms according to their needs. Color the background using faint peach and set component styles to coral.
