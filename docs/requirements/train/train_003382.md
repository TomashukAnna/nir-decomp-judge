# ТЗ № 3381 — WebGen-Bench train_003382

## Исходное ТЗ

Please implement a Xi Nian jewelry mall website for selling jewelry products. The website should have functionalities for product display, member management, point system, fission marketing, and distribution. Users should be able to browse products, join as members, earn points, participate in fission activities, and engage in distribution. Use powder blue for the outer layout and royal blue for UI blocks.
