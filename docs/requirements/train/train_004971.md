# ТЗ № 4970 — WebGen-Bench train_004971

## Исходное ТЗ

Please implement a web application for a virtual file system to simulate a real file system. The application should have functionalities for creating, deleting, and renaming files and folders. Users should be able to browse the virtual file system, create new files and folders, delete unnecessary files and folders, rename files and folders, and view file and folder properties. Configure the background color to glacier blue, with components using royal blue.
