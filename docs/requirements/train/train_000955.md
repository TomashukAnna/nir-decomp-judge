# ТЗ № 954 — WebGen-Bench train_000955

## Исходное ТЗ

Please implement a personalized form customization website for creating and managing custom forms. The website should have functionalities for creating forms, editing forms, deleting forms, form caching, and restoring form states. Users should be able to create new forms, add or remove form fields, set field relationships, and save forms for later editing. The forms should support various field types, including text, selection, date, and more, and should allow for conditional judgments and logical operations. Define background as opal; define components with indigo.
