# ТЗ № 4626 — WebGen-Bench train_004627

## Исходное ТЗ

Please implement a warning system for receiving and sending warning messages. The system should have the functionality to receive warning messages, filter them based on predefined rules, and send the warnings to relevant personnel through multiple channels (such as SMS, WeChat, email, APP). Users should be able to log in to the system, view warning messages, manage warning rules, and set up how they receive warning messages. Apply peach to the canvas background and orangered to all visible components.
