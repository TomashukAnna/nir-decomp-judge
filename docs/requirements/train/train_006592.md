# ТЗ № 6591 — WebGen-Bench train_006592

## Исходное ТЗ

Please implement an online streaming platform that provides streaming services for various types of content. The platform should have functionalities for user registration, login, content browsing, playback, and collection. Users should be able to register an account, log in to the platform, browse and search for various types of content such as movies, TV shows, live streams, etc., play selected content, and collect favorite content. The platform should also have content management functionality, where administrators can add, delete, and edit content. Set the background to porcelain, and apply olive to components.
