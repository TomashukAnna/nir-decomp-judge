# ТЗ № 834 — WebGen-Bench train_000835

## Исходное ТЗ

Please implement a COVID-19 pandemic data visualization website to display coronavirus pandemic data. The website should have functionalities for data collection, data mining, and data visualization. Users should be able to browse the website, view real-time data and historical data, including the number of infected people, deaths, and recoveries, and visualize the data through charts, maps, and other forms. Apply snow for layout; use dim gray for buttons and cards.
