# ТЗ № 5639 — WebGen-Bench train_005640

## Исходное ТЗ

Please implement a web application for data research and visualization, used to study large data sources. The application should have functionalities for data import, data processing, and data visualization. Users should be able to log in, import data, process data, generate visualized charts, and analyze data. Set primary background to linen white and elements to burlywood.
