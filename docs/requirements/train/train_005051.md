## Исходное ТЗ

Please implement a high-performance distributed database website for storing and managing large-scale data. The website should have functionalities for data storage, data retrieval, and data management. Users should be able to log in, create and manage their own databases, store and retrieve data, and perform queries and analysis on the data. Use aquamarine in the background layer and dark turquoise for the component layer.
