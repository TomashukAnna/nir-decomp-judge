# ТЗ № 5642 — WebGen-Bench train_005643

## Исходное ТЗ

Please implement a database monitoring website to monitor database host and database performance. The website should have functionalities for real-time monitoring, historical data query, and alert setting. Users should be able to log in, view real-time performance data of database hosts and databases, query historical performance data, set alert thresholds, and receive alert notifications. Use a pale ash background and apply slate gray to the UI components.
