# ТЗ № 6268 — WebGen-Bench train_006269

## Исходное ТЗ

Please implement an educational evaluation app to assess students' overall quality. The app should have multiple evaluation modules, including moral education, intellectual education, physical education, aesthetic education, and labor education. Users should be able to log in, browse different evaluation modules, fill out evaluation forms, submit evaluation reports, and view evaluation results. The app should also have data statistics and analysis functions, generating reports and charts based on evaluation results. Choose peach for global background and orangered for all components.
