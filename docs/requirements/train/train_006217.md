# ТЗ № 6216 — WebGen-Bench train_006217

## Исходное ТЗ

Please implement an online question bank system for teachers and students to take exams and practice. The system should have functionalities for teachers to freely create and manage question banks, set scores, conduct online exams, and view exam results in real-time. Teachers can log in to the system, create and manage question banks, create and set scores for exams, conduct online exams, and view exam results in real-time. Students can log in to the system, take online exams, view exam results and scores. Apply theme using light yellow as background and dark khaki for elements.
