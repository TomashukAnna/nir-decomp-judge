# ТЗ № 2507 — WebGen-Bench train_002508

## Исходное ТЗ

Please implement a virtual assistant website that provides brand development and copywriting services. The website should have functionalities for writing, editing, and reviewing. Users should be able to log in, submit writing tasks, and the virtual assistant can perform writing, editing, and reviewing based on the task requirements, returning high-quality results. The website should also have project management functionality, allowing users to track task progress and communicate with the virtual assistant. Design the site using powder blue as the background and medium blue for content blocks.
