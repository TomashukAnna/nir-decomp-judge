# ТЗ № 2493 — WebGen-Bench train_002494

## Исходное ТЗ

Please implement a Revit modeling assistant website for roads, bridges, and tunnels to aid in BIM design. The website should have functionalities such as 3D modeling of routes, placement of regular and adaptive families along routes, and simulated driving. Users should be able to log in, browse different design modules, and select corresponding functions for design and modeling. Choose seashell for global background and indian red for all components.
