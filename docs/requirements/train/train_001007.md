# ТЗ № 1006 — WebGen-Bench train_001007

## Исходное ТЗ

Please implement a digital human bank explanation website that displays digital human virtual images and explanation content. The website should have the functionality to display images, videos, text, and audio. Users should be able to browse digital human virtual images and view corresponding explanation content, including text and audio. The website should also have a search function, allowing users to quickly find specific digital humans and explanation content. Choose papaya whip for the background; set all component colors to peru.
