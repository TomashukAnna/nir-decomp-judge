# ТЗ № 3986 — WebGen-Bench train_003987

## Исходное ТЗ

Please implement a fund account management website for managing order account funds. The website should have functionalities for generating orders, making public payments, and collecting payments upon delivery. Users should be able to log in, browse order information, generate orders, make public payments, and verify payment records. The website should also be able to connect with the cargo transportation system to generate orders based on vehicle weight. Set the background color to desert sand and the component color to sienna.
