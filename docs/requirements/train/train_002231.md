# ТЗ № 2230 — WebGen-Bench train_002231

## Исходное ТЗ

Please implement a mini-program for foreign trade commodity procurement and sampling, used for recording and managing sample information. The mini-program should have functionalities for entering sample information, unified ordering, and generating electronic documents. Users should be able to enter sample information, generate orders, and automatically create corresponding electronic document content based on different types. The mini-program should also have customizable and intelligent features to meet the standardized needs of multiple cooperative factories. Use a plum background and apply dark magenta to the UI components.
