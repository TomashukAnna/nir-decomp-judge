# ТЗ № 2582 — WebGen-Bench train_002583

## Исходное ТЗ

Please implement a cryptocurrency trading bot for quick trading on exchanges. The bot should execute trades every minute and be able to detect and act on price changes quickly. Users should be able to set specific trading pairs and cryptocurrencies, and the bot should trade based on these settings. The bot should also display real-time trade records and account balances. Choose pearl for global background and charcoal for all components.
