# ТЗ № 5638 — WebGen-Bench train_005639

## Исходное ТЗ

Please implement a movie data visualization webpage to display movie-related information and data analysis. The webpage should have functionalities such as a movie section, a rating section, and a word cloud section. The movie section should display detailed movie information, including ranking, movie name, rating, number of reviews, a brief summary, and introduction. The rating section should provide a distribution graph of the top 250 movie ratings on Douban, including data views, bar charts, and line charts. The word cloud section should generate a word cloud based on hot words. Users should be able to browse movie information, view rating distributions, and word cloud analysis. Use cotton for the outer layout and maroon for UI blocks.
