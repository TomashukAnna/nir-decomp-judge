# ТЗ № 4390 — WebGen-Bench train_004391

## Исходное ТЗ

Please implement a fixed asset management system for managing and tracking assets. The system should have functionalities for asset management, procurement management, equipment management, and inventory management. Users should be able to log in, browse and manage assets, perform operations such as asset allocation, return, transfer, inventory, and view analysis reports. The system should also support custom fields, search, import, and export functions. Assign medium turquoise to the background and dark slate gray to the UI elements.
