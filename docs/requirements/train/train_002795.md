# ТЗ № 2794 — WebGen-Bench train_002795

## Исходное ТЗ

Please implement a multi-lingual accounting website that provides accounting services and information. The website should have a user-friendly interface, search functionality, diverse content types, responsive design, and an integrated admin panel. Users should be able to log in, browse accounting-related information, search for specific content, view different types of accounting services, and manage their account information. Set primary background to azure and elements to slate blue.
