# ТЗ № 4710 — WebGen-Bench train_004711

## Исходное ТЗ

Please implement a web-based database migration tool for managing and executing database migration operations. The tool should allow users to create, edit, and execute migration scripts, manage database versions, and view migration history. It should also have user login and permission management features to ensure that only authorized users can perform migration operations. Choose light sky blue for the background; set all component colors to deepskyblue.
