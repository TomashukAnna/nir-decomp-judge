# ТЗ № 3258 — WebGen-Bench train_003259

## Исходное ТЗ

Please implement a WeChat payment system to provide payment services. The system should have functionalities for payment, transfer, and payment of fees. Users can pay through WeChat or other payment methods, and the system will automatically complete the payment operation. The system should also have order management and transaction record functions, making it convenient for users to query and manage their transaction records. Declare medium aquamarine as the global background color and sea green for all UI pieces.
