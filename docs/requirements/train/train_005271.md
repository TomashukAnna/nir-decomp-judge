# ТЗ № 5270 — WebGen-Bench train_005271

## Исходное ТЗ

Please implement a database migration tool website to help users migrate databases. The website should have functionalities for database backup, restoration, and migration. Users should be able to log in, select the database to migrate, set migration parameters, execute the migration operation, and view the migration results. Select medium spring green for layout background and green for component details.
