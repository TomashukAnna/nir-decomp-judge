# ТЗ № 6621 — WebGen-Bench train_006622

## Исходное ТЗ

Please implement a multimedia in-vehicle entertainment system to provide in-vehicle information and entertainment services. The system should have functionalities for playing music, videos, navigation, and weather forecasting. Users should be able to browse and play multimedia files, view real-time traffic information, get weather forecasts, and control system settings. The system should also have voice control and gesture control functions to facilitate user operation. Use vanilla in the background layer and dark goldenrod for the component layer.
