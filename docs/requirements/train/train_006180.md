# ТЗ № 6179 — WebGen-Bench train_006180

## Исходное ТЗ

Please implement a marketing management platform for the education industry to improve the operating efficiency of educational institutions. The platform should have functionalities for course management, student information management, appointment scheduling, and class arrangement, meeting the core needs of the education industry. Users should be able to log in, browse and manage courses, student information, make appointments, and arrange classes, and view data analysis reports to support operational decision-making. Define the background as aquamarine and components as dark turquoise.
