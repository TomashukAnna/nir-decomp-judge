# ТЗ № 6238 — WebGen-Bench train_006239

## Исходное ТЗ

Please develop an online tutoring website for providing ISTQB advanced level test analysis training. The website should have functionalities for online teaching, test design, test management, and test automation. Users should be able to log in, browse courses, attend online tutoring sessions, submit assignments, and view grades. Teachers should be able to log in, create courses, upload materials, grade assignments, and communicate with students. Implement styling with beige for the background and brown for components.
