# ТЗ № 6598 — WebGen-Bench train_006599

## Исходное ТЗ

Please implement a danmu robot website for managing and automatically replying to danmu. The website should have functionalities for real-time danmu monitoring, gift thanks, follow thanks, timed advertising, and automatic replies. Users should be able to log in, set the robot's reply rules, monitor danmu, send gift thanks and follow thanks messages, and set timed advertisements. Use bisque for the outer layout and dark salmon for UI blocks.
