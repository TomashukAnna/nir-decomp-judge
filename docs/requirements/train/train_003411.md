# ТЗ № 3410 — WebGen-Bench train_003411

## Исходное ТЗ

Please implement a points exchange platform for exchanging goods and virtual goods. The platform should have functionalities for browsing goods, managing orders, managing members, managing points, managing product cards, and exchanging virtual goods. Users should be able to log in, browse goods, place orders to exchange goods, check order status, manage personal member information, query point balances, and exchange virtual goods. Apply light coral as the background; style all components with indian red.
