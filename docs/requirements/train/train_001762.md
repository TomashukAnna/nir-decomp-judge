# ТЗ № 1761 — WebGen-Bench train_001762

## Исходное ТЗ

Please implement a microservice development platform for building and managing microservice systems. The platform should have modular and plug-in functionality, allowing users to choose and combine different modules and plug-ins based on different business needs. Users should be able to register and log in to the platform, create and manage their own microservice systems, including adding, deleting, and configuring modules and plug-ins. The platform should also provide a public service layer, including user management, permission management, and log management. Use a light pink background and apply hotpink to the UI components.
