# ТЗ № 4958 — WebGen-Bench train_004959

## Исходное ТЗ

Please implement a database operation website for managing and operating databases. The website should have functionalities for querying, adding, deleting, and modifying data. Users should be able to log in, browse database tables, query data, add new data, delete selected data, and modify selected data. Set overall background to mint frost, then style components with seagreen.
