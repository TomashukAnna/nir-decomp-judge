# ТЗ № 6245 — WebGen-Bench train_006246

## Исходное ТЗ

Please implement a cultural center course registration website to solve course registration and management issues. The website should have functionalities for browsing courses, registering for courses, making payments, and management. Users should be able to log in, browse course information, select courses for registration, make online payments, and view registration records. Administrators should be able to manage course information, view registration status, and manage user information. Initialize the background color with light steel blue and component color with royal blue.
