# ТЗ № 5846 — WebGen-Bench train_005847

## Исходное ТЗ

Please implement a log viewer webpage to display uploaded CSV file data. The webpage should have functionalities for uploading files, displaying data, and chart display. Users should be able to upload a CSV file, and the webpage will display the data as a chart, including x and y axes, and be able to adjust the axis settings as needed. The chart should be a line graph, clearly showing the trend of the data. Choose antique white for the background; set all component colors to maroon.
