# ТЗ № 797 — WebGen-Bench train_000798

## Исходное ТЗ

Please implement a short drama video service website for playing and managing short drama videos. The website should have functionalities for user management, financial management, order management, playback management, authorization management, notification management, and consumption management. Users should be able to log in, browse and play short drama videos, manage personal information, perform recharge and consumption, view order status, and more. The website should also have backend management functionality for managing users, finances, orders, and video content. Configure your theme with gainsboro as background and dark slate blue as component color.
