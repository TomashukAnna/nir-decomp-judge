# ТЗ № 3911 — WebGen-Bench train_003912

## Исходное ТЗ

Please implement a second-hand car trading WeChat mini-program for buying and selling vehicles. Sellers can upload vehicle information, and buyers can upload personal information, including ID cards, faces, driver's licenses, etc. At the same time, buyers and sellers can browse vehicle information and conduct transactions. The system should have functions such as ID recognition, face recognition, driver's license recognition, and business license recognition. Apply white smoke to the canvas background and rosy brown to all visible components.
