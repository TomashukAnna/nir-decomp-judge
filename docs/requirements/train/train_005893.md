# ТЗ № 5892 — WebGen-Bench train_005893

## Исходное ТЗ

Please implement a Yōu Jiā Lì exhibition hall system platform to display real-time data statistics and monitoring information. The platform should have functionalities such as China map monitoring station data statistics, real-time statistics, real-time event list, chart statistics, real-time electrocardiogram, 3x3 grid electrocardiogram, chronic disease blood pressure platform, and real-time monitoring platform. Users should be able to browse real-time data, view historical statistical data, monitor real-time events, and use charts and electrocardiograms for analysis. Set overall background to pale lilac, then style components with dark orchid.
