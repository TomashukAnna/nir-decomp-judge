# ТЗ № 813 — WebGen-Bench train_000814

## Исходное ТЗ

Please implement a large screen display system for the Jinhua People's Congress Exhibition Hall. The system should have multiple screens, including vertical and horizontal screens, to display different content. Visitors can choose the content they want to view through touch screens. The system should have interactive functions, allowing users to browse and view exhibition content. Implement light blue for the page background and dark blue for the elements.
