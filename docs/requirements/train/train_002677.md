## Исходное ТЗ

Please implement a website that showcases a book reader application. The website should have a hero section that showcases the application, a tagline that emphasizes its unique features, and functionality to display application performance data such as downloads and analytics. Users should be able to browse the website, learn about the application's features and benefits, and download the application. The website should also provide application performance data, including download numbers and analytics. Select violet for layout background and indigo for component details.
