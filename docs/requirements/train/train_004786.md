# ТЗ № 4785 — WebGen-Bench train_004786

## Исходное ТЗ

Please implement a Grasshopper SMS compliance website for managing and sending text messages. The website should have functionalities for managing message templates, querying send records, and contact management. Users should be able to log in, create and edit message templates, send messages, query send records, and manage contact lists. Use cream for the outer layout and dark teal for UI blocks.
