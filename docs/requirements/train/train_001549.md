# ТЗ № 1548 — WebGen-Bench train_001549

## Исходное ТЗ

Please implement an instant messaging chat application for secure and private communication. The application should have real-time chat functionality, allowing users to create and join chat rooms, send and receive text, images, and files. Users should be able to register and log in to their accounts, manage their personal information and chat history. The application should also have search and filtering functions to help users quickly find specific chat rooms or messages. Choose glacier blue for global background and royal blue for all components.
