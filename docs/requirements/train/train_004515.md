# ТЗ № 4514 — WebGen-Bench train_004515

## Исходное ТЗ

Please implement a file upload tool to upload files to cloud storage. The tool should have functionalities for file selection, uploading, and information addition. Users should be able to select files to upload, upload files to cloud storage, and add file information to the database. The tool should support multiple file types and large file uploads. Set primary background to melon and elements to tomato.
