# ТЗ № 1627 — WebGen-Bench train_001628

## Исходное ТЗ

Please implement a multimedia encoding tool website for recording and converting audio and video. The website should have functionalities for uploading, converting, and downloading files. Users should be able to upload audio or video files, select the conversion format, set conversion parameters, and download the converted files. The website should also have a preview function, allowing users to preview uploaded files. Assign daisy white as the background color and apply khaki to all elements.
