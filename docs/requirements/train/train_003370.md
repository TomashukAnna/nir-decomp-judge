# ТЗ № 3369 — WebGen-Bench train_003370

## Исходное ТЗ

Please implement a payment system for an e-commerce SaaS platform to handle payments and point settlements. The system should have functionalities for member payments, point management, merchant registration, business settlement, and account reconciliation. Users should be able to log in, make payments, and query points, while merchants can register and conduct business settlements, and the system should simplify the account reconciliation process and improve order processing efficiency. Style the layout with desert sand in the background and sienna for the interface.
