# ТЗ № 3340 — WebGen-Bench train_003341

## Исходное ТЗ

Please implement a farm produce shopping WeChat mini-program that connects farm produce suppliers with consumers. The mini-program should have a multi-merchant entry function, where merchants can put up goods, and the background can be reviewed and approved. At the same time, it should have a multi-pickup point function, where customers can choose the nearest pickup point, and the pickup point can receive a commission. The mini-program should also have a function to release supply and demand information, as well as marketing functions, such as recharge gifts, point redemption, and coupons. Users can browse products, place orders, choose pickup points, and view order status, etc. Configure the background color to medium aquamarine, with components using sea green.
