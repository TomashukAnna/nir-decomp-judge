# ТЗ № 6469 — WebGen-Bench train_006470

## Исходное ТЗ

Please implement an instant messaging software for real-time communication between users. The software should have functionalities for registration, login, friend management, conversation management, message sending and receiving, and personal center. Users should be able to register an account, log in to the software, add friends, create conversations, send and receive messages, and manage their personal information. Style the layout with snow in the background and dim gray for the interface.
