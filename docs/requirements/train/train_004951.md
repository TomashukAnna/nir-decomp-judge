# ТЗ № 4950 — WebGen-Bench train_004951

## Исходное ТЗ

Please implement a lost and found system for publishing and managing lost item information. The system should have functionalities for posting lost item information, searching for lost items, and claiming lost items. Users should be able to log in, post their own lost item information, search for already posted lost item information, and claim their lost items. Implement styling with melon for the background and tomato for components.
