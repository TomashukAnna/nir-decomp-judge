# ТЗ № 2888 — WebGen-Bench train_002889

## Исходное ТЗ

Please implement a car inspection mini-program that displays car information and provides payment functionality. The mini-program should have features such as a homepage, product page, and report page. Users should be able to browse car information, make payments, select packages, query reports, and view orders. The mini-program should also have management functions such as report management, menu management, permission management, role management, news management, diary management, order management, user management, customer management, and merchant management. Set eggshell as the body background and use dark slate gray for the UI.
