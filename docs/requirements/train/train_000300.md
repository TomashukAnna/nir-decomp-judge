# ТЗ № 299 — WebGen-Bench train_000300

## Исходное ТЗ

Please implement an e-learning platform to provide educational content. The platform should have functionalities for course management, user management, and learning record management. Users should be able to log in, browse and select courses, submit assignments, view learning records, and communicate with teachers. Teachers should be able to manage courses, upload educational content, grade assignments, and view student learning records. Define the background as eggshell and components as dark slate gray.
