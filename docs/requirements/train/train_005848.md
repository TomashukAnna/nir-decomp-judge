# ТЗ № 5847 — WebGen-Bench train_005848

## Исходное ТЗ

Please implement a trauma big data platform for collecting and analyzing trauma medical records. The platform should have functionalities for data collection, data analysis, report generation, and permission control. Users should be able to log in, browse and manage trauma medical records, generate specified reports, customize reports, and perform data maintenance. The platform should be able to support the collection and analysis of pre-hospital, in-hospital, and post-hospital medical records. Set azure as the body background and use slate blue for the UI.
