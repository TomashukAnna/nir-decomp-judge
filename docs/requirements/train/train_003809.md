# ТЗ № 3808 — WebGen-Bench train_003809

## Исходное ТЗ

Please implement a multi-level marketing website for cryptocurrency investment. The website should have functionalities for registration, login, investment, and referral. Users should be able to register an account, log in to the website, browse different cryptocurrency investment opportunities, make investments, and refer other users to join the investment. The website should also have a personal center where users can view their investment records, referral records, and account balance. Use pale green for the outer layout and forest green for UI blocks.
