# ТЗ № 2535 — WebGen-Bench train_002536

## Исходное ТЗ

Please implement a backend management website for managing users, products, and data. The website should have functionalities for user management, permission management, product management, and data visualization. Users should be able to log in, browse user information, product lists, and data statistics, perform user add, delete, and modify operations, manage user permissions, add and manage products, and analyze data through charts. Design the site using pale lilac as the background and dark orchid for content blocks.
