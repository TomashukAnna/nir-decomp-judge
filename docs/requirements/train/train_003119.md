# ТЗ № 3118 — WebGen-Bench train_003119

## Исходное ТЗ

Please implement a Tian Shun Wisdom Health Care website that provides services such as elderly care, homestays, malls, and live streaming. The website should have functionalities such as elderly care bases, homestay hotels, health care malls, online live streaming, health care parks, healthy food courts, shared stores, and agency outlets. Users should be able to log in, browse different sections, shop online, book homestays, watch live streams, and query health information. The website should have payment and login functions to ensure the security of users' personal information and transactions. Set all pages to have a lavender blush background and deep pink components.
