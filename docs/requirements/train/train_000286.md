# ТЗ № 285 — WebGen-Bench train_000286

## Исходное ТЗ

Please implement an online learning system for providing cloud classroom services. The system should have functionalities for real-time communication, stable connections, asynchronous processing, and security measures. Users should be able to log in, browse courses, participate in interactions, submit assignments, and receive real-time classroom content and interactive messages. The system should be able to handle concurrent requests and ensure the security and privacy of user data. Assign pale turquoise to body backgrounds and medium turquoise to main components.
