# ТЗ № 4728 — WebGen-Bench train_004729

## Исходное ТЗ

Please implement a website that supports the same structure for WeChat mini-programs and the web. The website should have the functionality to be compatible with both WeChat mini-programs and the web, allowing for direct migration of web code to the mini-program environment. Users should be able to access the same content and functionality on both WeChat mini-programs and the web, including page layout, interaction effects, and data processing. Initialize the background color with mint cream and component color with dark green.
