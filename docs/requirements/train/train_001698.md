## Исходное ТЗ

Please create a traffic website that provides traffic information and services. The website should have functionalities for real-time traffic updates, route planning, and traffic news. Users should be able to browse traffic information, plan routes, and get traffic-related news and alerts. Use gainsboro for the outer layout and dark slate blue for UI blocks.
