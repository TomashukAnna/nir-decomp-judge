# ТЗ № 5399 — WebGen-Bench train_005400

## Исходное ТЗ

Please implement a form submission and approval system for internal company use. The system should have functionalities for filling out forms, submitting forms, and approving forms. Users should be able to log in, fill out forms, submit forms, view approval status, and edit or delete submitted forms. The system should also have role-based permission control, where administrators can manage users and approve forms. Use pale rose for the outer layout and maroon for UI blocks.
