# ТЗ № 1976 — WebGen-Bench train_001977

## Исходное ТЗ

Please implement a low-carbon project database website for storing and managing low-carbon project data. The website should have data import and export functions, supporting txt and excel file formats, and be able to perform data normalization detection and feedback on uploaded excel files. The website should also have a semantic recommendation function, which can recommend similar technologies based on project content. Users should be able to log in, browse and search low-carbon project data, upload and download data, and view recommended similar technologies. Apply pale rose to the canvas background and maroon to all visible components.
