# ТЗ № 2803 — WebGen-Bench train_002804

## Исходное ТЗ

Please implement a website for showcasing semiconductor components, used for displaying and managing semiconductor component information. The website should have functionalities for component classification display, search, and filtering. Users should be able to browse different categories of components, view detailed component information, and perform searches and filtering. The backend management system should have functionalities for maintaining, adding, deleting, and modifying component information. Style the layout with light salmon in the background and tomato for the interface.
