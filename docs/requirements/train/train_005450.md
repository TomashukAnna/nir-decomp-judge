# ТЗ № 5449 — WebGen-Bench train_005450

## Исходное ТЗ

Please implement a web plugin for form validation, used to validate user-inputted form data. The plugin should support various types of form validation, including text, email, phone number, etc., and be able to automatically detect and prompt users for input errors. Additionally, the plugin should also support validation for default values of select, checkbox, and radio options. Select pale green for layout background and sea green for component details.
