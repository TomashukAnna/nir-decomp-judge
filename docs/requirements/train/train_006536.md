# ТЗ № 6535 — WebGen-Bench train_006536

## Исходное ТЗ

Please implement an audio editing website for cutting, adjusting, and converting audio files. The website should have functionalities for cutting audio, adjusting volume, merging files, and converting file formats. Users should be able to upload audio files, select the start and end times for cutting, adjust the volume, merge multiple files, and convert file formats. Apply light salmon to the canvas background and tomato to all visible components.
