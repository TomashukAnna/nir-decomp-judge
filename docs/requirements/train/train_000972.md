# ТЗ № 971 — WebGen-Bench train_000972

## Исходное ТЗ

Please implement a cloud note website for recording and managing notes and tasks. The website should have task management functionality, including adding new tasks, modifying tasks, deleting tasks, and setting tasks as top priority. At the same time, the website should have note management functionality, including adding new notes, modifying notes, deleting notes, and using a built-in rich text editor. Users should be able to register and log in with their email accounts, change their passwords, and collect and share notes. The website should also have a recycle bin feature, allowing users to permanently delete or restore deleted notes and tasks. Set all pages to have a feather white background and dark green components.
