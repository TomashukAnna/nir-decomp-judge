# ТЗ № 3620 — WebGen-Bench train_003621

## Исходное ТЗ

Please implement a Digimon e-commerce platform for online shopping of daily necessities, books, clothing, shoes, toys, software, records, home appliances, and other products. The platform should have functions for browsing products, adding to cart, placing orders, making payments, and checking order status. Users should be able to register and log in, manage personal information, view consumption records, and evaluate products. Set page background to light salmon; color all components with coral.
