# ТЗ № 3079 — WebGen-Bench train_003080

## Исходное ТЗ

Please implement a WeChat mall mini-program for selling products and providing user services. The mini-program should have functionalities for browsing products, user management, coupon management, and order management. Users should be able to browse products, add products to their shopping cart, place orders, view order status, manage their personal information, and receive and use coupons. Use mint as the default background and dark sea green for component styling.
