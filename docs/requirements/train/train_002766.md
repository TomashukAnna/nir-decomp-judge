# ТЗ № 2765 — WebGen-Bench train_002766

## Исходное ТЗ

Please implement a WeChat mini-program to display project information and industry news for Hai Luo industrial factory buildings. The mini-program should have functions such as project information display, industry news browsing, distribution agent operation tools, and project assistant operation tools. Users should be able to browse project information, view news, use distribution agent and project assistant tools, and perform related operations. Assign linen white to body backgrounds and burlywood to main components.
