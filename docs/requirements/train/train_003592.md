# ТЗ № 3591 — WebGen-Bench train_003592

## Исходное ТЗ

Please implement a payment system website for payment and fund management. The website should have functionalities for payment, reconciliation, settlement, fund account management, and payment order management. Users should be able to log in, make payments, view statements, manage fund accounts, and query payment orders. Choose frost white for the background; set all component colors to charcoal.
