# ТЗ № 4790 — WebGen-Bench train_004791

## Исходное ТЗ

Please implement a website to control Wi-Fi networks for user authentication. The website should have functionalities for user login, registration, and password reset. Users should be able to log in and manage their Wi-Fi networks, including viewing network status and modifying network settings. The website should also have real-time monitoring and alert functions to keep users informed about network conditions. Set overall background to platinum, then style components with midnight blue.
