# ТЗ № 2086 — WebGen-Bench train_002087

## Исходное ТЗ

Please implement an online image annotation system for annotating image data. The system should have real-time collaboration functionality, supporting multiple users annotating online, and provide various annotation tools such as rectangles, free curves, and polygons. Users should be able to customize annotation types and attributes according to their needs. The system should also support data import and export and flexible data management. Users should be able to upload image resources, and the system should automatically parse them, and users should be able to download the annotated resources to their local machine. Choose white smoke for global background and rosy brown for all components.
