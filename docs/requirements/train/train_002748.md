# ТЗ № 2747 — WebGen-Bench train_002748

## Исходное ТЗ

Please convert the existing HTML website to a WordPress website, ensuring that the converted website has the same functionality and layout as the original website. The website should have a user-friendly interface, including a homepage, about page, contact page, and more, and should display all content and images correctly. The converted website should also support search engine optimization and responsive design. Use light beige for the outer layout and sienna for UI blocks.
