# ТЗ № 761 — WebGen-Bench train_000762

## Исходное ТЗ

Please implement a material intelligence cloud mini-program for device management and application processing. The mini-program should have functionalities such as device takeover, workshop inventory, allocation application, scrapping application, maintenance application, label management, and personal center. Users should be able to log in to the mini-program and perform device management according to their assigned permissions, including submitting various applications, approving and rejecting applications, etc. The mini-program should be able to display different menus and functions based on different user roles. Apply buttermilk for layout; use peru for buttons and cards.
