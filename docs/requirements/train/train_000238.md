# ТЗ № 237 — WebGen-Bench train_000238

## Исходное ТЗ

Please implement a casual game website for users to play and exchange goods. The website should have functionalities for user registration, login, task system, feeding chickens, collecting eggs, and exchanging goods. Users should be able to register and log in, browse task lists, complete tasks to earn feed, feed chickens, collect eggs, and use eggs to exchange goods. Apply theme using lemon mist as background and dark orange for elements.
