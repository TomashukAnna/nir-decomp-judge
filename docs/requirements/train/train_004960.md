# ТЗ № 4959 — WebGen-Bench train_004960

## Исходное ТЗ

Please implement a website to assist users in verifying Google applications. The website should have functionalities to guide users through the verification process, including entering Google account information and configuring Google Calendar. Users should be able to log in and follow the prompts to complete the verification process, with the website displaying the verification progress and results in real-time. Assign cloud white as the background color and apply midnight blue to all elements.
