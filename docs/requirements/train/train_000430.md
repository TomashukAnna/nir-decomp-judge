# ТЗ № 429 — WebGen-Bench train_000430

## Исходное ТЗ

Please implement a Hippopotamus supply chain management website for managing supply chain orders and entry audits. The website should have functionalities for entry, product library, product selection, ordering, after-sales, and risk control. Users should be able to log in, browse the product library, select products, place orders, view after-sales information, and perform risk control management. The backend should have order management and entry audit functions, and administrators should be able to view and manage orders, and audit entry applications. Select aquamarine for layout background and dark turquoise for component details.
