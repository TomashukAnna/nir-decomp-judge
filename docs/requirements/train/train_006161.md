# ТЗ № 6160 — WebGen-Bench train_006161

## Исходное ТЗ

Please implement a high school exam guidance website that provides related information and services. The website should have functionalities such as high school exam subject selection, professional assessment, high school exam data, volunteer registration, and information hotspots. Users should be able to log in, browse high school exam-related information, conduct professional assessments, view high school exam data, register volunteers, and obtain the latest information hotspots. Use light yellow in the background layer and goldenrod for the component layer.
