# ТЗ № 3989 — WebGen-Bench train_003990

## Исходное ТЗ

Please implement a Lemon Check website that provides functions such as service provider management and vehicle information inquiry. The website should have functionalities for service provider management, operational promotion, distribution management, order management, and ticket application. Users should be able to log in, browse service provider information and vehicle information, query maintenance and repair reports and accident reports, and perform order management. Assign white smoke to the background and rosy brown to the UI elements.
