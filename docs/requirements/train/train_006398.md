# ТЗ № 6397 — WebGen-Bench train_006398

## Исходное ТЗ

Please implement an online logo generator website that helps users create personalized logos. The website should have functionalities for selecting templates, customizing text, colors, and icons. Users should be able to choose from different types of logo templates, input company names and slogans, select suitable colors and icons, preview, and download the generated logos. The website should also have registration and login functionality, allowing users to save and manage their own logo designs. Set the background color to ghost white and the component color to cadet blue.
