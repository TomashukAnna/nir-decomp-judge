# ТЗ № 3672 — WebGen-Bench train_003673

## Исходное ТЗ

Please implement an office supplies mall website for selling office supplies. The website should have functionalities for browsing products, searching, shopping cart, placing orders, and order management. Users should be able to log in, browse office supplies, search for specific products, add items to the shopping cart, place orders for selected items, and manage their own orders. Configure all backgrounds with buttermilk and all components with peru.
