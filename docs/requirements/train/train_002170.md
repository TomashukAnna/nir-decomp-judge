# ТЗ № 2169 — WebGen-Bench train_002170

## Исходное ТЗ

Please implement a website based on TEMPLI php to display and manage data. The website should have functionalities for displaying data, adding data, modifying data, and deleting data. Users should be able to log in, browse data, add new data, modify existing data, and delete unnecessary data. Configure your theme with cool gray as background and charcoal as component color.
