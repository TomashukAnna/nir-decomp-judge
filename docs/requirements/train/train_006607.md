## Исходное ТЗ

Please implement a movie recommendation website that provides personalized movie suggestions based on user input. The website should have a user input form that allows users to enter their movie preferences, such as favorite genres, actors, and directors. After submitting their input, the website should display a list of ten movie suggestions that align with the user's interests, including movie title, genre, and a brief description. The website should also have user login and registration functionality to provide personalized recommendations. Use light coral as the screen background and brown for component highlights.
