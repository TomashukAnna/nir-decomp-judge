# ТЗ № 47 — WebGen-Bench 000048

## Исходное ТЗ

Please implement a time attendance system to record employee attendance. The system should have functionalities for employee clocking in and out, and viewing attendance records. Employees should be able to clock in and out, and view their own attendance records, including attendance time and absence time. Administrators should be able to view all employees' attendance records, perform statistics, and analysis. Specify papaya whip as the base color and dark orange for all components.

## Ограничения трактовки

Из требований исключены дополнительные условия прежнего разбора: заранее заданный график, фиксированные формулы расчёта, обязательные фильтры, интерактивный анализ, стартовые страницы по ролям, перезагрузка и повторный вход как условия сохранения, точность до секунды и заданный формат времени. Они не следуют из этого ТЗ и не входят в JSON для судьи. Пропуски в ID оставлены, чтобы не менять идентификаторы сохранённых требований.
