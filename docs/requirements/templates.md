# Первые шаблоны банка требований

Каталог в configs/requirement-bank.json связывает шаблоны с глобальными ID исходной разметки. У каждой записи есть критерий, условия применимости, параметры и способ проверки. В будущей оценке шаблон применяется только после сопоставления с конкретным требованием ТЗ.

Проверка ui.background_color сравнивает ожидаемый цвет с вычисленными цветами, которые поставляет браузер для уже выбранной видимой области. При отсутствии наблюдений или неподдерживаемом формате цвета возвращается UNRESOLVED. Выбор области и получение браузерных наблюдений остаются частью функционального этапа. Цвет блока интерфейса и цвет основного фона рассматриваются отдельно.

Два шаблона личного кабинета используют LLM, поскольку навигация, состояние входа и форма отображения данных различаются между приложениями. Исходные метки в разметке сохранены. Тип проверки в банке описывает способ, предусмотренный этой версией шаблона.

Проверка схемы и ссылок:

```powershell
uv run python -m decomp_judge.requirement_templates
```

Эта версия — набор шаблонов и один детерминированный проверяющий модуль. Подбор шаблонов из нового ТЗ и их вызов из судьи ещё не подключены.
