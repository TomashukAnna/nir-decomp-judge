# Результаты двухэтапного судьи

Одна папка — один запуск. Внутри каждой две задачи; у каждой свой README с ТЗ,
сравнением «человек / один промпт / агент / браузерный агент» и разбором результата.

| Запуск | Что проверяли | Задача 26 | Задача 39 |
| --- | --- | --- | --- |
| Запуск преподавателя, 18 ноября 2026 | До исправлений | [Открыть](run-01-supervisor/task26/README.md) | [Открыть](run-01-supervisor/task39/README.md) |
| Первый локальный запуск, до исправлений, 19 ноября 2026 | До исправлений | [Открыть](run-02-local/task26/README.md) | [Открыть](run-02-local/task39/README.md) |
| Локальный запуск после исправлений, 19 ноября 2026 | После исправлений функционального этапа и возврата JSON | [Открыть](run-03-fixed/task26/README.md) | [Открыть](run-03-fixed/task39/README.md) |

Начинать просмотр актуального результата следует с **run-03-fixed**.
Предыдущие запуски оставлены для сравнения и диагностики.

В каждой папке задачи только три основных файла: README.md, comparison.csv и run.json.
Полученные ответы и свидетельства собраны в artifacts/.

Человеческой разметки задачи 26 нет. Невалидный ответ судьи не считается FAIL приложения.
Формально принятый ответ также может содержать ошибку рассуждения: спорные выводы
явно отмечены в README соответствующей задачи. Базовые оценки одного промпта и
агента повторяются в таблицах как фиксированные ориентиры, а не как новые прогоны.
